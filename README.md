## Projects

### 🌿 Plant Health Predictor
[GitHub Repo](https://github.com/TmoodGitHub/plant-health-predictor)

An AI-powered plant health analysis tool that accepts multiple photos of a plant taken over time and returns a structured health report, pattern analysis, and prediction. Identifies the plant by common name, scientific name, and family, analyzes each image for health indicators, detects patterns across the full sequence, and predicts the plant's trajectory over the next 7-14 days with specific recommended actions. Built with a Node.js/Express backend, the Anthropic Claude API (claude-opus-4-5 vision model) for image analysis, and session-based file handling via Multer, with local JSON persistence for analysis history and exportable health reports.

`Node.js` `Express` `Anthropic Claude API` `Vision/Multimodal AI` `Multer` `Prompt Engineering`

### 🔧 tmoodgit
[GitHub Repo](https://github.com/TmoodGitHub/tmoodgit)

A fully functional Git implementation built from scratch in Node.js, not a wrapper, not a tutorial follow-along. Implements the actual internals: content-addressable object storage (blob, tree, commit), SHA-1 hashing, a JSON-backed staging index, branch refs, HEAD resolution, and working tree restoration on checkout. Ships a complete CLI with `init`, `add`, `commit`, `log`, `status`, `diff`, `branch`, `checkout`, and more, including a line-level LCS diff engine.

`Node.js` `Git internals` `Content-addressable storage` `SHA-1 hashing` `LCS diff` `CLI`
